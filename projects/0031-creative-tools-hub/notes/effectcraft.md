# 0014 · EffectCraft · 动效编辑与导出验证

**一句话：把已有视频、图片和文字放到时间轴上，制作动画、合成，再导出视频的编辑工具。** 本次已实测导入、中文标题、位置与透明度关键帧、保存重开、修改及 MP4 导出。

PixelFX 提供像素动态素材；EffectCraft 负责把素材和文字组织成可修改的成片。本轮新增的标题由 EffectCraft 渲染，底下水彩画面来自此前 0010 的自制视频；不能把整段水彩动画算成 EffectCraft 生成。

## 它对我们有什么用

给已有短片做片头、标题、字幕和叠层动画，或对文字、颜色、位置、出现时刻做后期修改。它提供可保存的图层与关键帧项目，还有适合自动化的命令入口。本次修改保留了原画面，只操作新增文字层。

它是早期的动效与视频合成编辑器。官方还声明有三维图层、摄影机和灯光等合成功能；本轮没有测试这些，也没有验证它能建立写实三维世界。官方对功能覆盖和成熟度的估计不是本次实测结论。

## 本机真正跑通了什么

1. 从官方 Release 获取 Windows x64 免安装包，下载量 85,071,674 字节；解压前 SHA256 与 GitHub 官方 digest 一致。
2. 使用包内 `effectcraft-cli.exe mcp` 启动无窗口引擎。版本状态确认为 0.24.1；本次为 CPU 合成，没有进行桌面 UI 或 GPU 操作。
3. 导入本库 0010 的 `picture.mp4`，导入返回无错误、无警告；渲染中看到真实底片内容。
4. 新增两个中文文字层，使用本机 Microsoft YaHei。为透明度设置淡入/淡出关键帧，为标题设置轻微上移关键帧。
5. 保存 V1，关闭引擎，再重新打开 V1。看图发现新增标题覆盖了原素材自带的“风来”文字，V2 改为右上方的“风经过的地方”，调整颜色、字号和副标题。
6. 两版均由 EffectCraft 原生导出 H264 MP4。FFprobe 检查均为 6.000 秒、144 帧、24 fps、640×360，无音轨；还提取了修改版编码后的真实视频帧查看。
7. 原生导出前后帧检查：新增文字完全透明的起止时刻，两版像素完全一致；中间时刻确有差异。没有重画或替换底片。

## 耗时与边界

| 项目 | 本机结果 |
| --- | --- |
| 初稿 6 秒视频导出 | 1.882 秒 |
| 修改版 6 秒视频导出 | 1.962 秒 |
| 修改属性的引擎调用 | 0.0052 秒，仅已编写脚本的执行，不含人工看图、设计、编码或导出 |

这些是 Windows 本机、CPU 合成、640×360 六秒小样的时间，不能外推成长片、4K、多层特效项目的性能。程序下载与环境准备也不包含在导出时间中。

**判断：作为已有短片的标题与后期合成工具，初步用途成立。** 保存后精确修改文字层比较直接。尚未验证桌面编辑体验、复杂时间轴、音频工作流、三维合成、高分辨率稳定性或全部内置效果，暂不称为成熟替代方案。

## 运行与复现

官方免安装包保留在总库忽略目录 `.local/effectcraft-runtime/v0.24.1/`，没有运行全局安装。原始包及其许可不进入本研究项目提交；CLI 配置通过 `EFFECTCRAFT_CONFIG_DIR` 指向本项目 `.cache/config`。

先按 [BRIEF.md](BRIEF.md) 的固定 Release 获取并校验免安装包，并准备 0010 原有的 `episodes/wind-in-the-garden/renders/v2/picture.mp4`。然后在总库根目录执行：

```powershell
python -X utf8 projects/0014-effectcraft-trial/scripts/build_trial.py
python -X utf8 projects/0014-effectcraft-trial/scripts/revise_trial.py
```

这两步使用官方引擎的 stdio MCP 命令接口，不通过鼠标操作桌面。视频由 EffectCraft 自身编码；外部 FFmpeg/FFprobe 只用于已导出文件的抽帧和校验，没有代替 EffectCraft 完成导出。

可编辑 `.ecproj` 引用本地底片路径；换机器需要准备相同素材或重新运行脚本。`renders/`、配置缓存和运行日志被 Git 忽略。记录只陈述实际跑通部分，不将官方文档里的功能列表冒充本机验收。
