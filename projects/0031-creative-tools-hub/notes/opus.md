## 怎样理解价值

阅读顺序固定为：**原作效果 → 具体价值 → 参考文字 → 我们的目标 → 取舍与补充 → 改写提示词**。视频、英文原文节选、我们的中文概括和新任务书各自标明身份。资料统计放在阅读页末尾，供需要时查阅。

## 参考文字怎样使用

第一条是直接描述目标的指令；后两条是作者的系列介绍或结果说明，上游标为不完整。页面展示简短英文节选、独立中文概括和完整原文链接，不把帖文包装成完整配方。

每个案例都明确：原文哪些内容被保留、哪些因我们的方向而改变、哪些验收要求是我们新增的。改写延续“人物建立情绪关系、自然通过事物变化展开”的方向，尚未证明这些输入能得到预期成片。

## 本地阅读与维护

阅读页是独立HTML文件，直接打开不需要安装依赖。也可使用本机已有Python预览：

```powershell
python -m http.server 53015 --bind 127.0.0.1 --directory projects/0015-opus-video-prompt-guide
```

浏览器打开本地地址 `/web/index.html`。仅绑定127.0.0.1，未公开发布。视频和海报由 `media.skillry.dev` 远程提供，受网络与来源可用性影响，不自动播放；加载失败时可进入署名的来源页。

`selected-cases.json` 是三条精选内容的来源，修改后运行：

```powershell
python projects/0015-opus-video-prompt-guide/scripts/render_reading.py
```

它只把内容嵌入独立HTML，无需运行时读取JSON。数据核对脚本 `scripts/audit.py` 使用标准库，从忽略目录 `.cache/videos.json` 读取固定703条版本，保留另行记录的播放和UI验证字段。原创路线图由 `scripts/make_overview.py` 生成，需本机已有Pillow和微软雅黑字体。
