# 0024 · Rea-Video · 把参考片拆成制作方案

先看作者效果与拆解产物，再理解价值：[本地阅读页](web/index.html)。

**一句话：把参考视频翻译成镜头、证据、素材要求与制作路线。** 核心输出是给人看的报告，以及供AI和程序继续读取的VIDEO.md拆片包。成片由后续拍摄、生成、三维或代码工具制作。

## 先看作者的实际示例

1. [纸艺／水彩动画四版对照](https://github.com/JuneYaooo/rea-video/blob/07dd587119e884f7c50fbfae92e47840de86bea5/README.md#remakes)：原片、OiiOii复刻、作者团队复刻、元素替换。画面中“我们的复刻”指作者团队，四栏都不是本轮作品。已实播观察开场与结尾；片长30.139秒、1280×720。
2. [混合人物与界面参考片的作者报告](https://github.com/JuneYaooo/rea-video/blob/07dd587119e884f7c50fbfae92e47840de86bea5/docs/cases/dual_role/report_en.md)：约19秒、10个镜头。页面摘出前四镜，分为画面、报告推断、复做建议与待核实项；不是本轮重跑的结果。

四版对照的完整生成使用了作者说明的capsule-cinema等下游链路及模型。Rea-Video的分析产物与影片生成分别归因。原仓库提供的媒体远程加载，没有下载或镜像副本；嵌入受网络与来源可用性影响。

## 对我们的价值

我们原本逐片看画面、记镜头和整理参考。它提供结构化的时间线、字幕／声音等记录、素材清单、推断与复做建议，方便交给后续制作工具。对反复研究参考、多人或多工具接力尤其值得评估；是否更准、更省时尚未同片实测。

参考的价值是理解人物、镜头、节奏和画面如何成立，再用自有素材发展自己的作品。反推提示词是制作建议，不能当作准确恢复的原始提示词或工程。艺术方向仍需要我们决定。

## 它提供什么

- 人读的`report.html`／PDF：内容结构、分镜、字幕和声音、制作方式推断、复做步骤。
- `VIDEO.md`：概览、目录地图、镜头时间线、逐镜细节与复做路线，按需要逐层读取。
- 时间线的`made~`、`material~`等字段明确表示推断，并保留置信度、备选和复核标记。

源码定位见[source-notes.json](source-notes.json)。已核对pipeline.py的分镜与分析流程，以及videomd.py的字段和文件写出逻辑；没有安装或执行它们。

## 参考后的目标与提示词

[原创任务书](OUR_BRIEF.md)先分析我们自己的24秒《风来小庭》，检查人物入口与自然展开的关系，再规划20秒雨后庭院。区分切镜与单镜头内部的注意力转移，将事实、测量、推断和未知分开。新增场景和素材按我们的方向设计，不套用作者角色与音乐。

该任务仅为输入草案：未分析自有视频，没有本轮工具报告、编辑工程或成片。网页包含取舍表与完整可选取提示词。

## 本地阅读与维护

静态HTML／CSS／少量JavaScript，不需安装框架。视频只使用作者原仓库的远程地址，不自动播放。`page-data.json`存储示例、报告摘要与我们的任务，修改后从本项目目录运行`python scripts/render_reading.py`重新嵌入。

```powershell
python -m http.server 53024 --bind 127.0.0.1 --directory <本项目绝对目录>
```

打开`/web/index.html`。未公开部署，登记表的demo_url保持null。本轮先在授权D盘目录完成轻量文件，再视F盘空间逐文件校验同步；不执行磁盘清理。
