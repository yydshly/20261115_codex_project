## 我们形成的理解

它是一个用网页代码编排素材、制作动画并导出视频的框架。比如已有数字人口播：讲到数字时出现图表，讲到案例时切到图片或视频，讲完后回到人物。位置、出现时间、动画和字幕都可修改，最后导出MP4。人物、配音和场景素材由我们准备，或通过相应服务生成。该例为理解说明，尚未制作本机小样。

相关清单的下一项是Remotion及Remotion Skills，已有0001动画图谱研究；随后可看[Blender MCP / MCP for Blender](http〈本机研究路径〉

## 它负责哪一步

按官方文档，HyperFrames使用HTML、CSS、媒体和可定位到特定时刻的动画构成工程，再渲染MP4。本轮未安装或实测本机引擎。素材可以是已有口播、图片、图表或场景视频；数字人生成需要HeyGen等相应素材与服务。

我们的采用判断：值得作为网页素材与数据转视频的补充候选，现有AI+Remotion主线继续沿用。EffectCraft与它都有编排能力；本次关注的是HTML创作与渲染路线，不推断两者只能二选一，也不凭官方的一次对照认定普遍优劣。

## 版本与验证

研究日期2026-11-17。官方源码固定提交`b29e40d707d6942953265e0dfc90a18fd98f654e`，通过GitHub连接器读取README、许可证和三份案例文档。视频URL由官方页面实际视频元素与文档核对；远端媒体字节没有固定为本地快照。

已实播三个官方示例：人物片观察30秒与42秒附近；图表观察2.8秒附近；产品片到达15秒结尾，并回看4.5秒。人物与图表样片已在本地页播放；产品片在官方页可播，但本地嵌入持续缓冲，页面保留明确提示与官方入口。三个案例切换、片段定位、全文选取和390px无横向溢出已检查。详见[验证记录](verification.json)。没有本机框架安装、渲染、确定性、中文音画同步、改稿耗时或迁移验证；未承诺节省比例。

预览命令使用已有Python标准库，监听127.0.0.1：

```powershell
python -m http.server 53022 --bind 127.0.0.1 --directory <本项目绝对目录>
```

打开`/web/index.html`。阅读页本身不需要依赖安装；源码中的JSON已嵌入HTML，直接打开文件也可切换案例，远程视频仍需网络。未配置或执行公开部署。

案例内容源是`cases.json`。修改后运行`python scripts/render_reading.py`（从本项目目录执行）即可重新嵌入独立网页；最后再检查三个案例。
