# 0013 · PixelFX · 像素动态素材实测

**PixelFX 是什么：一套由代码生成、可以修改参数的像素风动态特效素材。** 它提供雨、火、烟、水纹、花瓣、爆炸等动态零件，可以实时运行或导出为动画图片。房屋、地形、人物、地图、游戏逻辑和完整世界仍由我们制作；放入 3D 场景后仍然是像素风，不能靠提高分辨率变成写实效果。对当前写实自然体验方向，保留作备用素材，继续评估原清单中的其他工具。此结论来自本次六款效果接入和雨/水纹对照，不代表整库所有效果均已验收。

**最新一章：雨后归来。** 在六款效果接入之后，庭院已扩成 704×448 的连续世界。角色可以走动和绕岸寻路，点亮三盏晚归灯、给花圃浇水、和猫同行，最后回家泡茶。雨会浇花、熄灭露天火，花开后保留实际花朵；灯、花、猫和归家状态会在当前浏览器记住。世界原创绘景与真实特效使用同一套像素缓冲，本地运行，无声音。

**PixelFX 的实际贡献另做了控制实验：** [同场景 A/B/C 同步对照与一轮返修](COMPARISON.md)。固定机位和世界状态，比较关闭、当前、自然风格返修三版；参数修改加首轮静帧核对实测 2 分 19 秒，完整任务与导出另有记录。可直接打开 [同步对照页](htt〈本机研究路径〉 或 [12 秒对照片](renders/comparison/abc-synchronized.mp4)。

**判断：对像素游戏和浏览器场景有较直接的复用价值。** 篝火、萤火、水纹和花开可以保留现成的运动、颗粒和光晕；改色、调光、调速也直接。收益主要是少写一套特效，而场景、遮挡、碰撞和事件关系仍由我们完成。本轮为独立样例，尚未合入 0005《风归小庭》。

## 六款效果做到了什么

| 效果 | 实际保留的原效果 | 本次场景处理 |
| --- | --- | --- |
| 萤火虫 | 远近分层、不同游动路径、独立闪烁与柔光 | 去掉原效果自带草丛与底色，前后层接入庭院；可改金绿、月蓝等色 |

## 实际接入边界

**天气效果不全是透明贴纸。** 萤火虫、雨和花瓣都带一些背景或地面。直接整层叠加会影响庭院。我们在三份源码中各增加了 `overlay` 条件：仅在庭院模式下跳过这些装饰绘制；不传此选项时默认输出不变。其他三款效果及核心库原样使用。

**原色不等于适合任何场景。** 第一版将同一条暖色 ramp 用于所有效果，雨和水纹也被染成了黄绿。看图后改为分别处理：自然火焰保留原色，雨保持冷色，池水使用蓝青，萤火与花瓣再做柔和调色。月蓝/花信粉则作为明确的试验配色。

**颜色与光是两份缓冲。** 本次实际使用 `createFrame`、`createFx`、`drawBack/draw`、`composite`；前后层与池塘区域由宿主处理。当前光晕仍是屏幕空间叠加，不是带阴影的物理光照。

## 验证结果

环境：Windows、Node.js 22.15.0、FFmpeg 6.1.3、内置 Chromium。运行时无需 npm 依赖、图像生成或云端模型。

- 官方工具：先运行 `node tools/render.mjs fire/torch` 并查看 contact sheet，随后渲染六款候选；`tools/check.mjs` 六项 **6 pass / 0 fail / 0 warnings**。
- 源像素一致性：六款在 0、0.7、1.4 秒分别比较颜色缓冲和加光缓冲，默认参数下与本机固定提交的上游输出一致。此结论只覆盖抽样时刻，不冒充逐帧穷举。
- 场景检查：相同种子可重复得到相同像素；改色改变实际输出；光照开关改变合成；花开与点击水纹结束后移除。
- 实际 UI：四种场景、独立原效果、调色、速度到 0.4×、暂停/继续、重置、池塘点击、花开按钮均已操作。浏览器日志无错误；390×844 视口下文档宽度 375 px，无横向溢出。
- 精灵图：实际用官方工具导出 `water/ripples` 的 60 帧透明 PNG 与 Aseprite 风格 JSON，产物位于 `.local/pixelfx-upstream/records/water/ripples/`。未导入 Godot、Unity 或其他引擎验证。
- 动态预览：20.000 秒、600 帧、30 fps、1280×720，源缓冲 320×180，最近邻放大；本次生成约 6.82 秒。该时间只含已有场景的离线渲染，不含研究、绘景、接入和浏览器验证。

详细记录：[verification.json](verification.json)、[render-record.json](render-record.json)、[source-manifest.json](source-manifest.json)。Node 单次帧耗时只做本机参考，不是浏览器 FPS 测量或普遍性能保证。

## 尚未验证与限制

- 只验证六款，不代表其他 238 款、角色打击演出或整套工具都已验收。
- 雨滴没有与屋檐和地形碰撞，溅水主要落在效果预设的底部高度；篝火在雨天仍持续是展示选择。
- 花开是短时一次性效果，结束后不会留下永久花朵；需由游戏状态另外决定是否种下花。
- 全场景调速会同时影响循环和一次性事件，真实游戏往往需要分离世界时间与特效时间。
- 像素素材、场景与交互是独立小样，不是完整游戏。与既有庭院融合还需对齐像素尺度、朝向、遮挡、颜色和事件时机。
- 浏览器下载快照的自动验收超时，本轮已去掉额外的保存画面按钮；核心预览、交互与离线媒体输出可用。

## 运行与复现

```powershell
cd projects/0013-pixelfx-garden-trial/web
npm start
npm run check
npm run build
npm run render
npm run render:world
```

`npm start` 仅绑定 `127.0.0.1:53013`；结束时在启动终端按 Ctrl+C。`check` 的上游逐像素比对需要研究缓存中的固定版本，其他机器需先准备 `.local/pixelfx-upstream`；没有该缓存时只执行宿主检查，输出中不会出现上游比对条目。源码自带选用的依赖文件，运行不需下载完整库。`web/dist` 使用相对路径，未配置部署。
