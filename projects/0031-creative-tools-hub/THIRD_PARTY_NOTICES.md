# 第三方内容与署名

本项目的中文研究、任务整理、网页与汇总图排版为本库创作。图像作为解释库价值的署名缩图引用，不构成可任意再分发的素材包；各仓库代码许可不自动延伸到作者影片、图片、字体、模型和音乐。

- **Lemo-Opuscar**：Lemo-Opuscar by Lemomo / LemoLab，《Follow the Rain／跟着雨走》，[原作](https://lemomo-ai.github.io/lemo-opuscar/zh/styles/watercolor/)，[CC BY4.0](https://creativecommons.org/licenses/by/4.0/)。本图选帧、并排、缩小并转JPEG；42秒和22秒是选帧时点。右侧《风来小庭》是本库24秒试制，另见[制作来源](licenses/0010-CREDITS)。
- **PixelFX**：Patch / PixelFX；图为原效果本机运行快照，不是作者网页截图。原通知列明Hugo Duprez / Sprite Fusion、Hollow Crown / rehan-remade等来源与MIT条款，完整保留[NOTICE](licenses/0013-NOTICE.txt)。
- **EffectCraft、Remotion、Three.js**：图与发布的本地试制视频为本库作品或场景；分别说明工具贡献，未复制微软雅黑字体文件。Remotion Skills与Remotion共用一个样片。
- **Unslop**：Damir Sokolovsky / @heydamir，[固定提交](https://github.com/heydamir/unslop/tree/620163eedb3529d9cd23a3994ed8d287d06f760d)，[CC BY4.0](https://creativecommons.org/licenses/by/4.0/)。作者完成稿缩小并转JPEG，保留[许可正文](licenses/0027-UPSTREAM-LICENSE.txt)和[原通知](licenses/0027-UPSTREAM-NOTICE.md)。数字为作者公开示例UI，不表示本库真实业务。
- **Rea-Video**：JuneYaooo作者发布的四版对照，“我们的复刻”指Rea作者团队。完整成片包含其他制作工具和素材的贡献。
- **Awesome Opus Videos**：@anduraio原作海报，由Skillry公开展示；收集库本身不生成该画面，未将站方复刻标为原作。
- **HyperFrames**：HeyGen官方讲解片42.6秒选帧，缩为960×540；不保存或分发完整作者影片。
- **ComfyUI**：官方SD1.5图生图教程结果，非本机新生成。读取原始像素流后省略Pillow无法接受的元数据，再转JPEG；未修图。
- **Impeccable**：Paul Bakaus发布的旅馆案例缩图，保留原作入口；不把代码Apache-2.0解释为所有官网素材的授权。
- **Anthropic Skills**：Anthropic于2025-11-12发布的历史示例，非2026固定版本重测。
- **GSAP、Blender MCP**：图为本库原创静态构成／连接原理，不是原作者画面或新运行截图；官方演示保持原站入口。

上述Rea、Opus、HyperFrames、ComfyUI、Impeccable和Anthropic图像仅说明来源与研究引用范围，不宣称均获得独立素材再分发许可。原权利归相关权利人。
