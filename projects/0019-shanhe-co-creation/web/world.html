02

岚角族：先有轮廓，再有文化

工作名与美术探索；角色身份和量产规格尚未正式定稿。

种族身份

高地盘羊式非人类族群；鲜明种族轮廓，不直接复刻牛头人的造型与文化。

轮廓与比例

外卷盘角、短羊吻、厚实躯干、粗毛、宽掌和分蹄。成人比例、稳重且可亲。

材质与配色

青绿粗织物、赭红腰带、风化暖色角质、木材、岩石与旧铜。

文化与使用

共同作业、广门洞和宽路径；曲线纹样应有文化和使用依据，不能靠每件物品都印盘角来统一。

毛发、角、蹄足、衣服、体型和动画都增加实际制作难度；概念图并没有解决这些工程问题。
03

三位贯穿故事的人

名字、人物弧和分工来自当前故事草案；不能把同一张渔夫图当作三个人的定稿。

01

洛恩

修渠匠 / 从可靠伙伴走向权力冲突

避免十八年前的灾难再次发生。

实践救人 → 以标准获得信任 → 隐瞒石湾的代价 → 接受分散判断 → 交还独断权、承担后果

工匠身份、工具与铜木材质待设计，尚无专属定稿图。
02

渡石

渔夫兼领路人 / 多年的自责与对家园的执念

守住湖岸，不再经历失去。

接待新人但回避旧事 → 公开传信往事 → 面对自己房屋占用缓水通路 → 主动搬迁并参与救援

现有渔夫图可作参照；姓名和剧情身份属于助手草案，不能等同用户已确认。
03

岚织

织工与记录者 / 从简化答案到保留可检验的过程

让不同人的经验被理解，减少争执。

记录材料 → 删去失败步骤 → 发现自己也在丢失上下文 → 改进试验与记分 → 整理《六水录》

角色外形、服装、年龄与动作尚未设计。
04

从图像到真正可操控的角色

以下是候选制作流程。目前只有二维概念图，尚无模型、骨骼、动画或联网资产。

  1. 01

    定义身份与轮廓

    种族、比例、角与蹄足结构、服饰文化、同角色正侧背参照。

    检查：成人感、远距离辨认和角色/环境一致性。
  2. 02

    制作或选择三维初模

    可编辑的网格源文件；现成授权模型、定制或 AI 初模均为候选路线。

    检查：背面、手、角、衣物分层和实际轮廓，不能以生成图代替。
  3. 03

    整理游戏资产

    适合变形的结构、UV、材质、合理细节和分层道具。

    检查：关节、穿插、接缝与近远观看效果。
  4. 04

    骨骼与权重

    身体骨骼、蒙皮；特殊蹄足、角、毛发与衣物的处理。

    检查：自动绑定只能作为起点，非人类比例需要专门检查。
  5. 05

    生活动作

    站立、走跑、转向、挥手、坐下、抛竿、等待、收竿。

    检查：握杆、手臂、蹄足接地与服装变形。
  6. 06

    接入引擎

    模型、骨骼、动画、角色控制与道具连接。

    检查：实际游戏距离、镜头、碰撞、动画衔接。
  7. 07

    多人场景验证

    角色状态与动作同步的可运行验证。

    检查：双人相互看见与动作一致、断线恢复、场景负载；尚未实施。
