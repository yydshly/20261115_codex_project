# 我们怎样把100个网站带回自己的创作

好设计的价值不止在于“看到了效果”，还在于能解释它为何成立，并据此作出下一步创作决定。本项目把原文100个网站整理成参考库：保留原网址和九类，展示有出处的预览，逐项说明效果、实现原理、项目用途与判断范围。引导图使用本轮生成的[效果、原理与价值总览原图](assets/effects-principles-value-overview-v1.png)。

## 先分清资源在制作中的作用

| 资源 | 我们主要带回什么 | 怎样使用 |
| --- | --- | --- |
| 大赛与奖项 | 质量标尺与差距 | 选同类任务，对照构图、视觉层级、运动与完成度，再查制作说明 |
| 动态设计与视频 | 时间、节奏与镜头承接 | 从风格帧、动态分镜到动作和声画关系，先做短小片段 |
| 3D与渲染 | 几何、材质、光照和相机的分工 | 先用简单模型定空间，再逐层替换资产与调光 |
| 电影画面与镜头参考 | 构图、机位、明暗、视线和情绪关系 | 将感觉写成镜头条件；静帧无法证明运动和完整叙事 |
| UI设计 | 任务、状态与反馈 | 先列用户任务，再补选中、等待、空状态、错误、恢复和键盘操作 |
| 网页灵感 | 信息顺序、版式与阅读节奏 | 用同一份内容先确定主次，再安排网格、文字、图片与响应式 |
| 前端与交互 | 输入如何改变状态和画面 | 按问题选择CSS、动画库、三维引擎或着色器，先复用一个可解释的小机制 |
| 字体与配色 | 可以重复使用的视觉规则 | 将字号、间距与语义颜色沉淀为CSS变量、主题或字幕规范 |
| 日常收集灵感 | 能找回的选择依据 | 保存来源、适用任务、选择理由与使用限制，按创作目的组成参考集合 |

## 从“喜欢”走到能执行的决定

1. **看清效果**：说出具体体验，例如空间有层次、镜头连贯或操作有回应，并指出对应的画面证据。
2. **拆分原理**：判断它依赖哪些素材、结构、时间和交互规则。官方过程、视觉推断与通用实现路线分别注明。
3. **做小样**：一次只试一个固定镜头、片段或组件；先控制可比较的条件。
4. **比较差异**：保持同内容或同机位，对照修改前后，判断真正改善了什么。
5. **沉淀规则**：留下参数、分镜、组件约定或选择理由，让下一次创作能够接着使用。

资产站提供输入，规范提供约束，代码实现变化，电影与成片提供观察目标。把这些角色接起来，才形成适合自己任务的制作路线。具体工具是否适合，应由目标画面、交互、性能和维护成本共同决定。

## 对我们四类任务的价值

| 我们的任务 | 可以形成的具体产物 | 第一步小样 |
| --- | --- | --- |
| 庭院与自然三维世界 | 场景资产选择、空间尺度、灯光与相机方案 | 一个固定机位，保存调光前后的同画面对照 |
| 水彩与剧情短片 | 风格帧、分镜、时长表、动作及声音规则 | 六个镜头的动态分镜，检查视线与动作承接 |
| 研究网页与资料导航 | 阅读顺序、排版尺度、状态组件与来源入口 | 同内容两版页面，比较找到结论与证据所需步骤 |
| 把参考交给AI执行 | 任务书、视觉参数、保持项与可变项、验收依据 | 一个组件或片段，再按同一标准定向修改 |

这些产物是后续复用方向，本轮没有据此改动其他项目，也不表示四条路线已经完成实装。

## 证据与当前边界

- 100站保留原文编号及链接，分为九类；98站有真实预览。ArtStation与Web Design Museum未取得可用图，保留入口与缺图原因。
- 100份独立解析含128条资料引用，其中45项为官方资料结合复用建议、5项视觉推断、50项通用实现方案。通用方案不能写成源作已确认技术栈。
- 静态缩略图能说明构图和部分视觉关系，不能替代完整视频、实时交互或工具操作。详情链接返回原站或对应示例核实。
- 网站截图、活动照片、官方分享图、作品图和关联移植效果分别注明类型。图片、品牌与作品权利仍归原权利人；引用不授予商用或再分发许可。
- 收费和访问标记沿用原文与采集时的公开信息；未标付费不表示全站免费，当前规则以官网为准。
