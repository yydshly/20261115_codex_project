# 本地验收记录

2026-11-16，北京时间。环境：Windows、Python 3.10.11、Node.js 22.15.0、Codex 内置浏览器。故事、参考与网页的验证分别记录。

## 检查的完整流程

从原片情境阅读 → 创作价值与方向 → 七份故事筛选 → 全文和场景阅读 → 下载可继续填写的创作任务书。纯静态网页没有API、账户或数据库；数据来自本项目research.json和stories.json，经构建写入web/data.js。

## 遇到的问题与处理

- 受限进程启动的预览不能被浏览器访问。改为经过沙箱审核的本机临时静态服务后，HTTP返回200，并完成上述实际交互。
- 早期正文字号较小，已调大主要研究文字与故事正文，并为窄屏保持13px正文。
- 桌面故事目录长于可用高度，已为目录增加内部滚动；完整方向筛选后EW-007可实际选择。
- 内置浏览器URL策略只允许HTTP/HTTPS，直接file协议打开被策略阻止。没有绕过这一限制；文件方式的直接打开未完成浏览器实测。本页不依赖fetch或外部脚本，离线阅读基于代码和本地资源检查；实际交互证据来自本地HTTP。

以上是首次本地验收阶段的范围，当时未接入部署，未上传第三方视频。当前网页发布状态与线上核验另见publication.md。临时验收服务在完成后停止，后续预览可运行start.cmd。双击网页的方式尚未在内置浏览器中实测，不能与已通过的HTTP验收混为一谈。
