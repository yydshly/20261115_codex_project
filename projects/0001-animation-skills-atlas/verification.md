# 展示页验证记录

日期：2026-11-15。范围仅限本项目的本地展示页。

## 环境与流程

Windows；Python 3.10.11；Node.js 22.15.0；Codex 内置浏览器。使用仅绑定 `127.0.0.1` 的 Python 静态服务预览，无数据库、后端 API、凭据或第三方前端运行依赖。

完整用户流程是：读取本地结构化资料 → 浏览目录 → 搜索 / 筛选 → 查看项目说明 → 复制需求 → 选择制作路线或查阅上游来源。

## 文件检查

- `node --check` 检查两份 JavaScript 文件。
- 目录数据检查 18 项资源编号、唯一 ID、仓库地址、六类分类、2 个官方技能入口及 13 个技能说明。
- HTML 资源采用相对链接，适合嵌套目录；无根路径 `/assets/`。
- `python scripts/projects.py render` 同步首页后运行 `check` 校验登记表、目录、图片与首页同步。

本记录中的文件检查应以本轮最终命令结果为准；浏览器结果对应上述实际操作。

## 验证限制

没有逐一安装或运行 18 项上游工具，没有生成上游视频作品，没有验证 Muse 虚拟机，也没有把本站 CSS / SVG 示意当作某个上游工具的运行结果。

本站未部署，`demo_url` 保持 `null`。直接打开 `web/index.html` 的离线运行由源码结构支持，但本轮完整交互检查使用 HTTP 预览；不同浏览器的本地文件剪贴板限制仍可能不同，页面提供了复制降级处理。
