MAKE ROOM FOR A SLOWER DAY

留一点空，给生活走进来。

布置自己的庭院，也收下邻居捎来的小故事。

布置、来信与它们的意义 ↗

一张长椅，两只花盆。

开始布置后，选物件、点地面看落点，再按“放好”。长椅与茶桌一起搬动，两只花盆可分别调整；小径有三种走向、两种铺面。用箭头微调，左右看另一岸。会为花圃、门口和来往的脚步留路。

试试一个落点

一封信，把日常接起来。

阿岚住在故事里的隔壁。你的布置、选路和停留，会让后续来信慢慢到来。靠近庭院信箱按 E，或在这里拆信；进屋后也能在书桌边读。回信是作品内的故事选择，不会向现实中的人发送消息。

不设期限，不催回信；选过的话、读过的信和布置都会保存在当前浏览器。撤回布置，故事仍会留下。

A ROOM TO COME BACK TO

把赶路，留在门外。

沿小径到蓝瓦小屋前，靠近后按 R 进屋。

窗边看的是同一座实时庭院。可以在炉边歇息，读桌上的信，也可以开关桌灯；花圃和风铃的进度都会留下。

自动模式是作品里的缓慢昼夜与晴雨节奏，不对应真实天气。也可选一段喜欢的光线与天气停留；这些选择会随小庭保存。
