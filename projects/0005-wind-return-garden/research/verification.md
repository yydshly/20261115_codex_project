# 本地验收记录

日期：2026-11-15（Asia/Shanghai）。版本：本子项目独立 Canvas 2D 实现，工作区未提交。原文与素材出处见 [sources.md](sources.md)，素材原件与派生 PNG 的逐文件哈希见 [manifest.json](../web/assets/trees/manifest.json)。

## 用户故事

玩家进入庭院，沿地面或任务项走到三处风铃，读纸笺并控制一阵柔风；风场驱动真实素材的分层运动，成功后保存进度；完成三处后到长椅触发结尾，再继续散步。

此作品无应用 API、远程数据库或在线生成调用。验证链为：页面 → 本地素材加载 → 输入与路径 → 风场与游戏判定 → 画面及本作品 Local Storage → 重新加载。

## 环境

- Windows，Node.js 22.15.0、Python 3.10，素材处理使用本机已有 Pillow、numpy。
- Codex 内置 Chromium；最初宽屏视口报告 1280×720，实际截图约 1268×714。
- 窄屏实际视口 390×844；非真实手机设备。
- 原生 HTML/CSS/ES modules、Canvas 2D、Web Audio，无 npm 运行依赖。
- 只监听 `127.0.0.1:52845`。初次沙箱进程与浏览器隔离导致连接超时，随后用本机服务成功加载；最后改由已验证的隐藏窗口启动器维持本地体验。
