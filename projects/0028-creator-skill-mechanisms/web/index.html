07 / 这轮讨论怎样收敛

从“有没有价值”，问到“怎样约束”

  1. 最初的判断：第三方 Skill 带有个人体感，写作类内容主要值得参考。
  2. 补充价值：现成流程、工具和记录方式可以复用，不必全部从零。
  3. 第一次修正：只写“能做什么”太抽象，必须说明输入、处理和输出。
  4. 第二次修正：“省时间、少返工”还不足以解释价值，要拆开规则怎样约束、怎样引导目标。
  5. 形成当前理解：借具体机制，换入自己的样本与标准，再用作品反馈修订；文字规定、程序检查与实际效果分别验证。
