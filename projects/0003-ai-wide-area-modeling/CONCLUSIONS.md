# 从一张图到可编辑三维：我们的理解

我们的目标是同一份可以连续走动、进入咖啡店、回望街道，并能编辑物体和灯光的三维场景。照片感、共同空间、实体编辑、物理换光是四项独立验收。当前十次实验只证明了部分能力，完整场景尚未通过。

## 这条流程怎样分工

1. **输入与设计依据**：运河原图是 AI 概念图，没有其他真实视角、隐藏室内或尺度真值。原图看不到的部分属于推断或设计。
2. **空间估计**：COLMAP 用特征匹配、SfM 和可选 MVS；VGGT 用学习模型预测相机、深度和点等。COLMAP 不是单图补全器，VGGT 也不会自动给出完整房间拓扑。两者的输出都须核查。
3. **有约束的生成与补全**：补图要保持同一相机体系、三维点、遮挡、物体身份与已知区域。多张看起来相似的图片，不足以证明共用空间；必须检查对应点、重投影和跨门口连接。
4. **高斯外观**：3DGS 是三维表示，具有位置、形状、不透明度与颜色等，可训练拟合，也可由 SHARP 直接预测。多视图高斯可以从多角度观看；我们单图结果的可靠覆盖有限，不代表高斯天生只有一个方向。
5. **实体结构**：Blender 中的网格、层级、门轴、材质和灯承担编辑与控制。网格与高斯可以组合，但对象归属、坐标、遮挡、表面绑定和未见面外观需要处理。PLY 转网格不会自动得到干净可编辑拓扑。
6. **灯光与验证**：普通高斯的颜色包含原图的照明、阴影与反射。移动门、切换暖光/日光缓存，不等于物理重照明；真实换灯需要材料与照明分解或专门表示。

## 实际尝试与没有通过的地方

| 尝试 | 证明了什么 | 没有证明什么 |
| --- | --- | --- |
| 历史语义 Blender 场景 + 单图 VGGT 深度 | 可以得到空间预测并用于拟合 | 锚点 RMS 由 36.92px 变成 54.46px；目标与相机变化是混杂因素，不能把结果归结为 VGGT 无效 |
| 原图 → SHARP 单图高斯 | 生成 1,179,648 个高斯；原视角外观和邻近视差可展示 | 大侧移、近景、背面、室内和换光没有完成 |
| 高斯 + 新建 Blender 咖啡店 | 门轴联动、实体室内、实体换灯和 28 秒连续镜头跑通 | 原高斯近景拉伸、穿插、室内和背面覆盖仍有缺陷 |
| 完整实体场景 → RGB-D 融合高斯 | 同一设计场景可从多机位渲染；功能可对照 | 外观变成 CG，不能当原图高斯复原完成 |
| 保留原高斯并绑定实体 | 原机位保留外观，动作能传递 | 绑定不能消除错误结构、缺失表面、近景接缝和投影拉伸 |
| 左右及室内补图 | 通用图像模型能给候选外观 | 漂亮候选未稳定共用三维空间 |
| VGGT 一致性与门口 A/B 连接检验 | 得到相机、对应与冲突证据，定位连接失败 | 最后过渡图未通过；没有训练这批图的高斯 |

十次实验包括历史对照与独立视角诊断，完整记录、视频与工程以网页中的逐实验关联为准，不以表格中的合并行数计数。

## 对我们的价值与选择

- **可复用资产和影片预演**：将外观参考、实体结构与相机轨迹分开保存，可以持续检查走位、遮挡和镜头，而不重复猜场景。
- **保留判断依据**：已保存原图、预测、生成候选、失败画面、配置、哈希与工程；以后换模型也能用同一问题和同一验收比较。
- **避免无效堆流程**：先通过门口连接和跨视角一致性，再扩大区域和训练高斯。继续增加独立补图或模型细节不能代替空间检验。
- **产品与开源研究**：Atlas、PINOC／JST-2、ViewCrafter、GEN3C 等提供空间生成/补全路线参考；本图没有完成这些产品的实测，不能用厂商演示证明我们的目标已经达成。闭源内部实现未公开的部分保持未知。

现阶段适合继续做受相机与几何约束的局部补全，再验证、合并与绑定；是否采用专用空间生成模型另行比较。我们不把完整世界说成单纯“多图 → 高斯 → 网格”的格式转换。
