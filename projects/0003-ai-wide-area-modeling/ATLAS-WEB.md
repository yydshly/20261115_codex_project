## 架构所表达的边界

目标路线是原图／观测 → 相机与可见几何 → 未知空间补全 → 共同空间验收 → 高斯外观与实体结构 → 对齐／物体绑定 → 材质、动作和光照 → 最终可编辑交付。实拍多图可以核验后直接走向重建，遮挡处仍需补采。检查不通过要回到补全，不能把候选直接当训练真值。

独立实测支线是原图 → Apple SHARP → 单图高斯 PLY → Spark / Three.js 渲染，未使用 VGGT、COLMAP 或旧 Blender 输出。原机位附近较可靠，不代表完整世界。

VGGT 是学习几何的模型；COLMAP 是几何重建软件；3DGS 是表示／拟合／渲染方法；Blender 是资产创作工具；各环节组合起来才是流程。高斯和网格可以并行构建，绑定不是自动生成背面或独立换光。架构中的已实测标记只证明局部能力，目标链路虚线不宣称端到端通过。

ViewCrafter、GEN3C、WonderWorld、Atlas、JST-2 / PINOC、SuGaR、Frosting 和 LichtFeld Studio 仍按既有研究标记为本运河图未运行／未接入。没有新增外部服务调用、套餐价格确认或付费消耗。
