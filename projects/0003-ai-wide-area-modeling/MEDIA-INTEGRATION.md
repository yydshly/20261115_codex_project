已有咖啡店、原高斯绑定与完整实体 GLB 直接读取。另对下列 4 个既有工程只读打开，导出到新的 `.local/canal-research-web/previews/`：

## 一个服务，而非多个旧端口

`scripts/serve.py` 只监听 127.0.0.1:52933。视频、文件、Three.js／Spark 和查看器资源都通过同源路径读取，效果页不再依赖 8769／8771／8772／8773／8775 等旧服务是否运行。

查看器 HTML 在响应时产生展示副本，改写资源路径、适配画布宽度和 iframe 高度、加来源／限制说明；没有写入原查看器或场景文件。咖啡店全景增加相机拖动控制，仍使用原几何和 Blender 门矩阵。一次只加载一个主三维场景，切换或点击释放时卸载 iframe。

原始媒体和大工程不重复复制进站点或 Git。服务用登记 ID 映射精确原文件；支持 GET／HEAD 和视频单段 Range，未知 ID 返回 404，没有写回 API。模块和查看器资源路径检查必须留在指定根目录内。

静态导出包含完整项目图册与研究记录；大媒体、三维和工程能力需要本机只读服务。单独把静态 dist 上传不等于已经托管这些大文件。本轮未发布到外网。

## 验证结果

- 内置浏览器实际读到全部 6 段视频时长 3／28／4／12／28／36 秒；播放成功，28 秒影片可跳到末尾，无媒体错误。
- 全部 6 个三维／诊断入口实际加载。SHARP 1,179,648 个高斯；混合样板门开到 75°，室内日光与拖动可用；原高斯绑定版 1,128,344 个高斯；完整实体对照可切换实体模式与门；固定机位页载入原始高斯；VGGT 显示 3,960 个点和 7 个相机，并能过滤。
- 8 个 GLB 预览全部在浏览器读到网格，历史 V4 相机、部件搜索／聚焦与线框实际操作通过；程序材质差异在预览中如实保留。
- 原始提示词在页面原文对话框读取成功；按入口实验过滤得到 10 张效果原图并可放大。
- HTTP 只读检查通过全部 375 个登记文件的长度；8 个 GLB 文件头正确，6 段视频 Range 返回 206 与精确字节；未知文件 ID 返回 404。
- 首批 41 项原工程、原高斯、原 GLB 与视频逐文件 SHA-256 前后完全一致，包含历史 V3／V4。新导出的 4 个 GLB 单独保存。
- 22 项单元检查通过，包含 Range 边界、原工程下载命名、资源根目录边界、查看器 import map 和默认不公开发布本研究。
- 固定展示副本的画布宽度适配通过：嵌入画布约 782.7px、内部可用宽约 783px，没有横向裁切；iframe 随实际内容调整高度。390px 实际同源视口中文档宽约 375px，图册与历史工程筛选可操作，无横向溢出。
- 最终静态导出核对 137 项图像／证据哈希、150 个页面资源通过；本机大媒体不进入静态包。浏览器出现原渲染库的着色器 signed/unsigned 与旧软阴影回退警告，未见阻断加载的错误，未为此改写旧场景。

原高斯与完整空间的质量结论没有改变：可观看和检查不代表完整可编辑世界已通过。高斯仍有烘焙光照，新的室内与未见区域仍需设计和验证。
