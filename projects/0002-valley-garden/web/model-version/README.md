## 启动与独立构建

首次依赖安装在上一级 `web/` 执行 `npm ci --ignore-scripts`。本目录无需另装框架或依赖。

在本目录双击 `start.cmd`，或执行：

```powershell
npm start
```

它会复用原有本地服务并打开 `/model-version/`。两个版本使用同一服务，原版的 `stop.cmd` 会关闭该共享服务。全部模型和纹理已下载到项目内，运行时无需外部资源服务。

```powershell
npm run check
npm run build
```

- `check` 检查 JS 语法、原版 27 个文件的逐文件哈希、模型和材质下载哈希、外部 glTF 依赖，并在 CPU 中实际解析全部 27 组模型、核对窗洞玻璃、家具落地/边界、外墙碰撞、植被贴地、视野预算和地形/水面几何。CPU 验证不替代 GPU 与浏览器视觉验收。
- `build` 仅写本版 `model-version/dist/`，复制必要运行库、模型及共享材质，保持相对资源路径；不改写原版构建。
- 当放到未来站点时，本版可放于 `/20261115_codex_project/demos/0002-valley-garden/model-version/`。
- 操作与原版一致：WASD/方向键、拖动环顾、Shift 快步、晨暮/画质切换。设置新增“小屋风格”。
