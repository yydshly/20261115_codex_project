# 庭院石板表面

2026-11-16 从 [Poly Haven Rock 01](https://polyhaven.com/a/rock_01) 获取。作者 Rob Tuytel；[CC0](https://polyhaven.com/license)。官方标注原始尺寸 1.5 × 1.5 米，材质在场景中使用相同世界尺度。

采用官方 2K JPG Diffuse、nor_gl 和 Rough，未修改原图。逐文件下载地址、上游 MD5、本地 SHA256 见 manifest.json，下载后 MD5 全部一致。颜色为 sRGB，法线和粗糙度为非颜色数据。

这是连续、风化的实心石材表面，不含先前碎石地面的密集独立石粒。铺装板块是本地生成、沿真实庭院参考调整的拼合几何；不称为扫描石板模型。原版材质与原石径源码均未改写，旧模型版源码见项目 versions/model-v2-before-courtyard-refinement/。
