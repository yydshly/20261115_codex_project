# 溪谷花园 · 介绍与双版本展示

本地入口：`http://127.0.0.1:4173/overview/`。

从 `web/` 运行现有 `npm start` 即可，无新增依赖或构建步骤。本页独立保存在 `web/overview/`，保留 V1 的 `/` 和 V2 的 `/model-version/`；没有修改两个场景的源码、资产、启动器或构建。

## 内容

- 代码生成版与精致素材版的真实运行截图、独立入口。
- 页面内漫游体验台：手动启动、版本切换、结束、放大画面、独立打开。
- 空间构建、材质/光照、自然层次、生活反馈、迭代工作及价值对照。
- 从本次探索得到的理解：连续空间、资产整合、接地动作与位置声音。
- 当前原型的完成范围、局限、素材来源和氛围参考。

两版都由代码驱动。V1 的主体几何由程序生成，并已结合实拍 PBR/HDR；V2 为外部模型、PBR、真实高程与程序场景的混合制作。网页不把 V2 说成全场景高精外部模型，也不宣称确认或重建了参考视频的制作方式/地点。

## 素材与运行

`assets/code-overview.jpg` 和 `assets/models-overview.jpg` 为 2026-11-17 本聊天内置浏览器中的实际运行截图，均为 845 × 560 视窗，保留各版默认构图。它们并非相同相机位置的性能或画质基准。来源、日期及 SHA256 见 `assets/SOURCES.json`。

`capture.html?edition=code|models` 是本地取景辅助页：读取原场景 HTML，以其原路径为 base，在隔离 iframe 内隐藏 UI；不改动原场景文件，也不用于产品漫游。`capture.html?page=overview&width=390` 在实际内置浏览器中提供 390 × 620 的响应式检查视窗，不等同于真实手机验收。

介绍页默认只加载小体积截图；用户启动后才载入一个真实场景 iframe。切换、结束或离开页面时移除旧 iframe，停止旧场景及音频，避免重复运行。普通场景保留原有交互与默认静音行为。放大画面由用户点击触发，使用页面内展开以兼容内置浏览器；背景不可聚焦，支持还原和 Esc 退出。

没有发布、注册外部站点或更改根仓库 `demo_url`。此页依赖现有两个本地场景入口；未来发布需要连同它们的完整运行资源一起组织路径。

浏览器检查与保留校验见 [本轮记录](../../assets/qa-20261117-overview/REPORT.md)。

## 素材来源索引

介绍页的 `#asset-sources` 集中列出 37 条外部来源（含运行/处理依赖）和 12 条程序内容记录。每项包含场景元素、名称、适用版本、使用状态、来源网站、原始链接、作者、获取时许可、日期、本地路径与原记录入口。

- 支持关键词搜索、场景分类、外部/程序筛选、分类展开、单项深链接与关联来源跳转。
- JSON 和 UTF-8 BOM CSV 完整清单位于 `assets/source-catalog.json`、`assets/source-catalog.csv`，网页可直接下载。
- 原始依据仍是各素材目录的 `SOURCES.md`、`manifest.json` 和许可证原文。本索引不会覆盖它们，也不把网站许可当前状态与获取时记录混为一谈。
- 远山高程明确保留来源组合及署名，包含 CC BY 3.0 AT，不标为 CC0；人物与牛披露 AI 辅助来源，牛的静态资产与本地程序动作分开。
- 本地程序未单独声明素材许可，本轮没有为源码新增授权；派生模型仍列出原素材许可，Three.js / meshoptimizer 的 MIT 另列为依赖。

维护时先核对既有素材记录，再更新 `build-source-catalog.py` 的场景映射并执行：

```powershell
cd projects/0002-valley-garden/web/overview
python build-source-catalog.py
```

生成器只读素材记录，校验本地路径与关联 ID，输出介绍页的两份索引文件；遇到来源许可超出当前 CC0 映射会停止，要求先更新许可映射，不会静默沿用 CC0。原始素材记录和两个场景都不变。

本轮验证记录见 [素材来源索引检查](../../assets/qa-20261117-material-sources/REPORT.md)。
