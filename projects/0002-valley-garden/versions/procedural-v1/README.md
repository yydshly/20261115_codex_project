# 保留版本：程序化写实原型 V1

保留日期：2026-11-15。

原版本继续位于项目的 `web/` 根目录，入口 `http://127.0.0.1:4173/`，原来的 `web/start.cmd` 保持可用。本轮没有重写其源码或材质文件。

`manifest.json` 记录原版 27 个源码、启动/构建文件和材质文件的大小与 SHA-256。依赖目录、可重新生成的 `dist/`、本机运行状态和新增的 `model-version/` 不在基线中。该清单用于验证原文件保持不变；依赖仍由原版 `package-lock.json` 固定。
