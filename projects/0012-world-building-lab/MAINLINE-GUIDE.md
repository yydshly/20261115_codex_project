# 山海之间 · 雪岭到深海

[从雪岭开始环境主线](https://yydshly.github.io/20261115_codex_project/demos/0012-world-building-lab/expedition.html?walk=snow-to-deep#ice-1) · [网页中的建设顺序](https://yydshly.github.io/20261115_codex_project/demos/0012-world-building-lab/journey.html#mainline-roadmap)

主线用现代基座已实走的 2,483 米，把地形、水系、地表、植被和时间层串起来。进入一站后，先看场景，听或读讲解，按提示做一次对照，再前往下一站。前往下一站会沿原路线移动，到站停下来。站点下拉框可直接定位；从专题点「返回主线讲解」或关闭专题，都会返回原站和时期。

| 站点 | 要理解的现象 | 可操作的观察 |
| --- | --- | --- |
| 雪岭 | 山脊、分水岭和水汽怎样决定山地的来水方向 | 在地理底图找主山脊、水汽箭头和出海流域 |
| 冰碛湖 | 冰舌进退怎样改变冰湖和融水 | 在同一位置对照盛冰期和现在 |
| 源池 | 融水、坡面来水和地下储水怎样加入同一流域 | 去同流域北支泉口切换停雨 14 天，再回源池 |
| 中央河谷 | 河谷展宽后，泥沙如何留下河漫滩和土壤 | 打开河漫滩土层和植被剖面 |
| 苇泽湿地 | 洪泛和退水怎样改变植被分带 | 对照丰水期与退水 14 天 |
| 分汊河口 | 潮汐怎样改变盐度前缘、泥沙和低岸 | 切潮段，追踪一场雨的泥沙，回本站看暖期淹没 |
| 中央海湾 | 回读从山脊、入渗、侵蚀到岸线的关系 | 用三条环境线复盘，或进入三流域的同一场雨对照 |

「自由探索与时间对照」保留 12 个时间切片、10 个观察点及当期步行和航拍分段。其他地形和人类活动专题可从世界总览进入。

## 同一流域的形成剖面

[从雪岭打开 3D 形成剖面](https://yydshly.github.io/20261115_codex_project/demos/0012-world-building-lab/expedition.html?plan=ridge-bay&station=ridge&month=7#ice-1)。雪岭、源池、中央河谷、苇泽湿地、中央海湾五站共用现有地形和逐月水量收支。顺水线会带入当前月份，主线的「读本站地形剖面」会定位所在站。选择「到本站实地」可以回到对应的步行站。

图中地表线取自真实场景高程。水线、沉积量和淹水分带引用已有试算。苇泽湿地的水面、可淹低滩和植被含水表现会随月份变化。河谷浅槽和海湾加积线是用于解释形成过程的参考形态。

## 海湾到深海

主线前七站沿原有 2.48 公里步行段。中央海湾之后，沿西岸和南部外海绕过陆地，从东部岩岸进入浅海，沿现有海床前往浅海海草床、暖水礁坪、大陆架、大陆坡和海沟，全程约 10.46 公里。可点「连续导览」，也可逐站前往、暂停和继续。长距离航行和观测采用加速导览，水下停留时可用键盘在观察区内移动。

海段以现今海面为基准。沿线读取海床水深与自然底光，使用观察灯看深处底质和群落。浅海站可往返西南浑浊河口做对照，大陆坡站可往返热液与冷泉。新增海段先提供文字讲解。

内置浏览器从雪岭启动连续导览，经过中央海湾和东部岩岸，抵达深海海沟。路线进度显示 10,460 米。最终站海床水深为 370.5 米，采用当前场景尺度。

## 东部冷流带与海雾

东部岩岸前新增冷流带停靠点。固定入口气温和露点，原位切换冷流与较暖海面，观察暖湿空气是否冷却到露点。保持冷流不动，切换向岸风或离岸风，看雾在哪一侧聚集。展开温度带和箭头可分别查看近岸流向和风向，俯看时会保留主线进度。场景采用简化的海气换热和雾输送估算，能见度是渲染参考。[进入冷流与海雾站](https://yydshly.github.io/20261115_codex_project/demos/0012-world-building-lab/expedition.html?walk=snow-to-deep&station=coastal-fog#ice-1) · [美国国家气象局海雾说明](https://www.weather.gov/safety/fog-water)

## 语音

本地预览使用 MiniMax 的七段中文讲解。网页提供手动播放和到站自动讲解。讲稿与音频来源于同一份 [站点文本](web/mainline-lessons.js)，选择了 `speech-2.8-hd` 和男声有声书音色。生成器读取指定配置中的 `MINIMAX_API_KEY`，在 MiniMax 官方接口合成 MP3。浏览器只读取本地生成的音频。支持用 `MINIMAX_TTS_VOICE` 和 `MINIMAX_TTS_MODEL` 调整音色和模型。[MiniMax 官方语音合成接口](https://platform.minimax.io/docs/api-reference/speech-t2a-http)

修改讲稿后，重新生成变更站点的音频并更新预览。

```powershell
node --env-file='./.env.minimax' scripts/render-mainline-voice.mjs
python -X utf8 scripts/build.py
```

加 `--chapter=ridge` 可只合成雪岭一站。内容相同的音频会复用。

## 陆上步行与语音验收记录

内置浏览器从雪岭逐段走到中央海湾，终点显示 2,483 米。核对了途中暂停、恢复和专题返回，包含北支停雨、河漫滩植被、湿地退水、河口潮汐和泥沙。现场也切换了盛冰期冰碛湖和暖期河口，两站均能回到现在继续。七段 MiniMax MP3 均已核对可解码及与站点讲稿一致。 用最终版在雪岭手动播放 MiniMax 音频，步行抵达冰碛湖后自动播放下一站音频。[雪岭播放实景](assets/mainline-guide-ridge.jpg)

## 后续建设与验收

1. **验收连续主线。** 从雪岭连续导览到海沟，沿途中同一画面核对步行、沿岸航行和水下观测的接驳。海段从浅海看到陆架和大陆坡，水深、底光与群落应有可见变化。
2. **补齐影响整张现代地图的关系。** 现有航段已可对照海温、海雾与能见度。南部干湿过渡已接干谷灌丛的四个火后对照状态。现有天气线已接草原彩虹与日晕、戈壁蜃景、雷暴触地涡旋和海上气旋对照。现代图谱条目均有 3D 入口，场景精度和史前覆盖仍分开评估。
3. **沿同一主线复查史前。** 在雪岭、河口和陆架原位比较盛冰期、退冰期和现代，核对冰缘、岸线与古河槽的位置。顺水线里的苇泽湿地可以转入泥盆纪早期森林和石炭纪煤系沼泽，在同一坐标读取古根土、积水、泥炭和洪水覆泥。 「河口到深海」可切到寒武纪八站，沿河口砂坝、三角洲前缘、外海台缘到崖脚，对照两处化石记录代表的古海底。 「顺水」的河谷和湿地还能切到奇恩利组与莫里森组类比，沿同一组站位看洪水搬运倒木和季节性湖岸。
