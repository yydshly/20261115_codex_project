# 岩性与地下水

[打开原 3D 大地图](http://127.0.0.1:52932/expedition.html?plan=groundwater#build-1)

岩性着色使用地图里的实际地形网格。青岚山坡设为花岗质结晶岩，西北层状岩壁与干谷采用砂岩和泥岩，东部冷却熔岩归入玄武岩，北部峰林和洞网设为石灰岩。黄条纹表示冲积砂砾盖层，基岩类型仍保留在其下。分区是世界设定，为现有的海陆、山脉、火山弧和可溶岩地貌提供一致的区域背景。

| 顺序 | 观察内容 |
| --- | --- |
| 青岚结晶岩坡 | 看同雨条件下薄土和致密岩面怎样让较多水沿坡面流走，也有水进入风化带和裂隙 |
| 西北砂岩—泥岩阶地 | 看砂岩和泥岩从不同母岩提供粗、细颗粒。气候、坡度、植被和成土时间共同影响土层 |
| 东部玄武岩流 | 对照熔岩流冷却节理、流间带与较致密岩体的导水差异 |
| 北部冲积扇砂砾 | 观察搬来的砂砾盖层。较通畅的粒间孔隙可让水向下渗 |
| 干谷层间含水带 | 用定位剖面观察砂质含水层、低透水泥质层和随雨后变化的饱和带 |
| 绿洲接触带泉池 | 看层位与沟岸相交的出水点，泉水流进原有泉池。雨停后还可延迟出流 |
| 岩溶落水洞与地下河 | 打开现有多层洞网剖面，示踪水从落水洞经竖井和下层洞道进入地下河。洞道由长期溶蚀形成 |

干谷含水层和绿洲泉池属于同一个局地样例，北部岩溶洞网是独立的汇水系统。七站按学习次序组织。

北部冲积扇另有一个季节对照，可追踪砂砾带缓释的地下水进入北支、中央主河与苇泽湿地。[地表与地下水路](WATER-EXCHANGE.md)

## 同一场雨

比较把同样的 48 mm 分成 8 小时缓雨或 2 小时短时强雨。五个等面积样点使用相同初始水量。每小时先以样点入渗能力和根区剩余容量分配地表径流，入渗水的一部分通过连通裂隙或孔隙快速补给，其余先进入土层。土层超过蓄水阈值后继续下渗。地下的快、慢储库各以不同速率出流，可拖动时间看雨停后的区别。

每一帧的累计降雨等于地表径流、土层留水、地下蓄水和地下累计出流之和。参数描述本地图的样点，未加入蒸散、区域地下水交换或实测校准。剖面中的厚度与流线采用教学尺度，现有水体仍使用原地图的水位与季节逻辑。

资料参考 [USDA NRCS 土壤形成](https://www.nrcs.usda.gov/resources/education-and-teaching-materials/soil-facts)、[USGS 含水层与地下水](https://www.usgs.gov/water-science-school/science/aquifers-and-groundwater)和[USGS 岩溶补给及出流](https://pubs.usgs.gov/sir/2011/5146/pdf/sir2011-5146.pdf)。

## 三条环境线

- **顺水** 对照结晶岩坡和冲积扇，沿流域比较地表走水与浅层入渗。
- **南北冷暖** 在温度和湿度背景上加入风化母质，用不同地表对照同一气候带的土壤差异。
- **海岸到内陆** 从干谷向泉池追踪慢补给，解释少雨一侧为什么能维持局部湿地与绿带。

三线可以在原场景叠加岩性，也可以跳到对应水文站；返回恢复原站与月份。
