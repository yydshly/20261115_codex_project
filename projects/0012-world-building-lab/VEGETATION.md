# 植被：地形、地表、水域之上的场景层

本轮在原大地图上替换了旧的按区域散树方式，建立一套四层植被规则。地形、水系和设施仍属于同一个世界。植被专线沿原水系六站前进，海湾一站改到可观察滨岸植被的陆岸；水系主线仍保留原入海平台。

## 网页中怎样理解

1. 选择“植被 · 沿水读群落”，点击开始植被主线。六站依次经过高山、溪岸、河谷、淡水湿地、河口盐湿带、海湾岸带。
2. 每站先隐藏植被并显示生长分区，再加入乔木与灌木，最后补地被、水生植物。相机从实际植物位置选择无遮挡的观察方向。
3. 随时暂停，打开“植被图层”分别开关乔木、灌木、地被、水生。面板显示脚下地形的海拔、坡度、地表与场景湿润/盐湿参数。
4. “查看生长分区”将同一地形染成条件色；它是24米采样的分区示意，不是精确水岸或生物分布图。实际植株使用各自坐标的细采样条件。
5. 四条主线分别记录：构建76条、植被18条、水系30条、原地形30条。手记可导出Markdown，✓表示已经浏览。

## 构建顺序与参考价值

**地形与水位 → 生长条件 → 形态选择 → 四层组合 → 疏密与变化 → 通行及视线留白。**

| 输入 | 实际用于决定什么 | 对我们的参考价值 |
| --- | --- | --- |
| 海拔和坡度 | 高处压低株高；陡坡少放或不放；根部附着实际地形 | 先判断空间能承载什么，再选模型 |
| 草土、碎砾、湿泥、沙砾、灰岩等地表条件 | 草地、灌丛、裸地与旱生形态的取舍 | 地面覆盖和立体植物各有职责，不能互相替代 |
| 河流距离、床底高度、水面高度 | 判断深水、浅水和湿岸；区分根生与浮叶的高度基准 | 同一套水位数据要贯穿地貌与上层内容 |
| 场景湿润与盐湿参数 | 淡水湿地和河口/滨岸使用不同组合 | 水域类型也参与素材与分布选择 |
| 连续簇状密度场、确定性扰动 | 树群、空地、草丛的疏密节奏，尺寸与朝向变化 | 先组织群落的大关系，再补单株变化 |
| 道路、建筑、桥、栈道、观察点 | 避开通行面与设施，给人的视线留位置 | 自然内容与世界用途要共同设计 |

湿润度、盐湿影响和海拔分带均是本库的美术与教学参数。形态采用松、桦、柳、苇、莎草等常见外形提示，没有进行真实气候、土壤养分、盐度或物种生态校准。

## 六站内容

| 站点 | 主要观察 | 组合方法 |
| --- | --- | --- |
| 融雪源头 | 矮灌、短草、苔垫和大块雪岩留白 | 株高与密度回应高处薄土；较低缓坡才出现针叶树 |
| 跌水溪流 | 针叶树、矮灌与草岩过渡 | 水道、砾岸、坡土各用一组条件，保留跌水观看方向 |
| 河谷主河 | 阔叶/桦形树群、林缘灌丛、草地与花丛 | 乔木建立轮廓，灌木接住空隙，地被提供近景尺度，桥路留空 |
| 苇泽湿地 | 柳形树、蕨形林下层、挺水与浮叶植物 | 树木位于稳定露地；挺水从床底长起，浮叶以水面定位 |
| 分汊河口 | 低灌、盐湿草丛、水道与露地 | 低处减少高大树木，保持分汊轮廓；分区交界允许群落过渡 |
| 归水海湾 | 风塑松、滨岸低灌、岸草与浅水层 | 较高稳定陆岸承接乔木，低岸配置较矮形态，海水深处留白 |

更干旱的砂岩、沙丘和火山地带在原十站地形路线中对照，使用稀疏灌丛、旱生形态或枯木。岛屿保留棕榈形态。整体世界的规则与水系主线使用同一套生成代码。

## 实际分布规模

平原、盆地与内陆湖接入后，固定分布已扩展；当前实例总数及四层数量见[检查数据](assets/vegetation-distribution-check.json)，加入森林后共 **23种形态**。前轮10,115个实例的截图与验收记录保留在验证文档中。另有按相同规则更新的近景草丛，不计入固定实例数量。

渲染按种类、层级和空间分块实例化；远处保留较高轮廓，近处加载较低层次。总实例数与当前可见数不同，开关某一层不会改变固定分布本身。纯数据检查见[assets/vegetation-distribution-check.json](assets/vegetation-distribution-check.json)。

## 新增森林空间

[FOREST.md](FOREST.md)记录同一林地中的林缘、密林、林下与林窗。新增高冠乔木形态、连续树冠、蕨草苔垫、贴地倒木与开敞林窗，森林阶段的构建线为11站、44处观察，现加入地下段后为15站60处；植被专线仍保留原六站18处。

## 新增内陆环境

平原、盆地、湖岸和出湖河复用相同规则，增加淡水条件、地表覆盖与观察点让位，扩大固定地被和水岸采样范围。新构建主线逐层对照地形、地表、水域、植被；详见[INLAND-WORLD.md](INLAND-WORLD.md)。

## 对后续内容的价值

这些分布为后续内容提供条件：树群组织遮挡与远望，林缘灌丛组织过渡与隐藏空间，湿地和盐湿带区分资源与行进环境，留出的桥路和观察点承接人物活动。后续可以按我们的需要加入采集、动物、任务、营地和故事，而不必为每段场景重新随意堆素材。

本轮完成程序化展示与构建教学，没有植被生长、繁殖、季节更替、动态风场、生态AI、采集、游泳、船只物理或任务系统。相机导览不等于游戏级连续步行与寻路验收。模型与材质保持本库的原创程序化风格。
