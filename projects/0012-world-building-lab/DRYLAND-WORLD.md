# 草原、戈壁与绿洲：水源怎样改变空间

本库原创程序化教学样本，接入同一张大地图南部，追加第64—68站。当前68站272处观察，前63站与252个观察ID保留。湿热河口到草原用明确标注的教学镜头转场，五站内部保留连续实际地面通路。

[进入干湿五站](http://127.0.0.1:52932/expedition.html#dryland-1) · [直接看绿洲](http://127.0.0.1:52932/expedition.html#dryland-5)

| 场景 | 实际效果 | 参考与扩展价值 |
| --- | --- | --- |
| 连续草原 | 大范围低起伏草土、连续低草与开敞地平线 | 通过覆盖率与高度形成开敞空间，可继续扩展风动草浪与季节草色 |
| 林草过渡 | 一段疏林嵌入草原，树间保留空隙 | 用成簇树群和草地留白表现过渡，可扩展多种稀树群落 |
| 戈壁砾地 | 实际砾石、裸土与少量矮灌 | 区分砾地、沙丘和裸岩，可扩展砾石粒径、风蚀形体与干旱地表细节 |
| 干谷 | 下切沟床、两岸高差和向低处延伸的走向 | 区分地形沟谷与有水河道，可扩展冲洪积扇、阶地和间歇洪水 |
| 绿洲 | 真实池盆、12m水位、中心8m床底、湿岸草灌与局地冠树 | 水源先形成湿润岸带，再安排植被，可扩展泉水补给、用水场地和更丰富群落 |

每站四层为**地形骨架 → 地表与砾石 → 水源与干湿 → 植被与空间**。正式地形、真实水深、素材落点、小地图与主线共用数据。1965个草丛、2093块砾石、280个低灌和38株冠树使用实例几何，树干与石块避开观察路，深水池心不放陆生植被。

干湿参数在草原为0.62，戈壁约0.11，干谷附近约0.07；靠近绿洲水岸重新升高，池岸向外逐渐转回砂砾。参数只解释素材分布，不能当作真实土壤含水量。地表颜色、形状、是否存在明水、水深和植被分别制作；干谷保持无常流水，静态泉池没有模拟地下补给、蒸发或水量平衡。

“干湿全貌”俯看同一片草原、疏林、砾地、干谷与池盆，再次点击返回原位置。小地图直接用地形文字定位；WASD可沿路步行，深水边界阻止步行入池。
