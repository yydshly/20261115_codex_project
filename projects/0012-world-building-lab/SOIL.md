# 土壤形成与植被过渡

[打开大地图「土壤与植被」](http://127.0.0.1:52932/expedition.html?plan=soil#build-91)。从「流水与泥沙」进入可沿用所选月份和地点；原冲积扇、苇泽湿地和分汊河口观察站也提供直达入口。

| 观察段 | 母质、土层与植被 |
| --- | --- |
| 山口上游 | 山坡基岩分为易风化和较耐蚀的教学层。坡陡、径流容易带走细料的位置保留薄土或裸岩，缓处和坡脚留下更多细料，短草、苔垫与草灌随之增多。 |
| 北部冲积扇 | 粗料在扇顶比较集中，砾石多、蓄水少。往扇尾细料渐多，草与矮灌斑块逐渐变密。 |
| 苇泽湿地 | 细泥形成较厚、湿润的土层。高水漫上低岸，长期饱水的心土用灰蓝色表示。湿岸主要出现芦苇、莎草，较高地面有草和灌丛。 |
| 中央海湾 | 盐度指数随河口位置、岸地高度、离水距离与淡水出流改变。近海低滩仍湿润，但以耐盐草与矮灌为主，向较淡的上游侧逐渐过渡。 |

形成机制参考 [USDA NRCS 土壤与成土因素](https://www.nrcs.usda.gov/resources/education-and-teaching-materials/soil-facts) 与[河口盐沼的受淹和盐度分带研究](https://doi.org/10.1111/j.1365-2745.2004.00959.x)。

## 同地取样与季节变化

- 「土层剖面」沿原高度场抬起剖面，标出 A、B、C 三个位置。侧栏以厘米对照表土、心土和风化母质，下伏基底用灰色表示。抬起剖面的垂直比例用于观察。
- 「水分与盐度」用地表颜色呈现根区湿润度、淹水和相对盐度。切换月份时继续使用[流域收支](WATERSHED-BALANCE.md)的月度土壤存水和湿地水位，用湿地出流近似河口淡化。
- 「植被分布」复用现有草、灌、芦苇等三维形态。放置规则读取根区土层深度、粒径、全年含水、受淹月数与盐度；每月更新颜色和环境对照，植株落点固定。

土层来自长期背景估计。各站的沉积与冲刷使用[泥沙模型](SEDIMENT.md)的当月结果单独记账，全年沉积影响当地母质组成。四个样区采用创作参数与相对指数，河口淡化属于简化估计。潮汐往复、长期土层演变、营养与真实植物生长仍待构建。

| 样点对照 | 场景结果 |
| --- | --- |
| 山口 A 点上坡 → C 点坡脚 | 土层从 6 厘米到 40 厘米 |
| 扇面 A 点扇顶 → C 点扇尾 | 砾石占比从 57% 到 33%，土层从 38 厘米到 53 厘米 |
| 苇泽 B 点漫水边 | 1 月露出，7 月被淹，约 79 厘米土层仍按长期背景对照 |
| 河口 A 点近海低滩 → C 点上游侧 | 7 月盐度指数从 51 到 4。A 点 1 月指数为 77 |

自动检查验证四段土层和、12 月湿度与盐度范围、扇顶扇尾分选、湿地夏季越岸、河口咸淡过渡、盐生植物落点和恢复原植被。切月检查植株坐标固定，颜色和水盐状态响应。
