# 流水侵蚀、搬运和沉积

[打开 3D 大地图「流水与泥沙」](http://127.0.0.1:52932/expedition.html?plan=sediment#build-91)。也可从「流域收支」带着当月水量进入，或从原冲积扇、苇泽湿地、分汊河口观察站直接进入相应一段。

在泥沙面板点「看土壤与植被」，继续对照同一月份的[四段土壤与群落过渡](SOIL.md)。

| 地图观察点 | 形成条件和画面 |
| --- | --- |
| 山口上游 | 月降雨和融雪形成的坡面径流沿高度网格下行。看橙色轨迹和贴地冲刷痕迹。 |
| 北部冲积扇 | 水路出窄谷后分开，砂砾留在扇顶与分汊之间。看贴着原洲地形成的浅金色落砂带。 |
| 北部支谷 | 东支与另一支谷合流，再接中央主河。浅金与浅棕点划线分别表示两类泥沙，密度随当月搬运量变化。 |
| 苇泽湿地 | 将逐月水位与低岸高程比较。淹到的漫滩会留下一层细泥，转到「年内累积」并切到退水月份可看泥层露出。 |
| 中央海湾 | 河口分流扩散，砂砾留在原分汊间的浅脊，部分细泥继续输往湾外。「年内累积」显示砂洲逐渐扩展。 |

冲积扇依据 [USGS 冲积扇纵剖面研究](https://pubs.usgs.gov/publication/70000539)，漫滩依据 [Lauer 与 Parker 的河漫滩储沙研究](https://doi.org/10.1029/2006WR005529)，河口沙洲依据 [Edmonds 与 Slingerland 的河口沙洲研究](https://doi.org/10.1029/2006JF000574)。

## 模型范围

使用现有 [流域补给与水量账本](WATERSHED-BALANCE.md)的逐月地表径流、主河湿地水位及出流。40 米网格按原下坡边汇集径流与两类泥沙。坡面松散物供给随径流和坡度变化。山口、扇面、支谷、湖泊、主河、湿地和河口依次转交颗粒，输送上限由水量、坡降和代表宽度给出。北部支谷其余来沙在扇面下游接入，澄镜湖先拦留上游的一部分泥沙。

中央海湾流域每月按「新冲刷量 = 坡脚及河湖留存 + 河口留存 + 输向湾外」分别核对砂砾和细泥。沉积体积为场景估计，三维地表色层放大显示。扇面水位沿用原参考水路，中央主河与湿地采用当月水位。所选月份累积的是本年从 1 月起的沉积。潮汐和波浪、重新起沙、河床长期高程反馈仍待构建。

## 低水与高水对照

| 过程 | 1 月 | 7 月 |
| --- | ---: | ---: |
| 山口产沙坡面冲刷 | 0 m³ | 5.39 m³ |
| 扇面砂砾沉积 | 0 m³ | 1.02 m³ |
| 北部支谷向下游搬运 | 0.33 m³ | 70.19 m³ |
| 苇泽低岸被淹面积 | 0 m² | 约 1,765 m² |
| 河漫滩细泥沉积 | 0 m³ | 67.25 m³ |
| 河口沙洲砂砾沉积 | 0.53 m³ | 1.65 m³ |

12 个月均通过两类泥沙的收支核对。原观察站、通行路线与手记继续沿用。
