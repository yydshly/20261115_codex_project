# 冰雪环境：雪山、冰川、冰湖与融水溪流

本轮在原大地图北侧建立冰雪高地，并把融水接回原有212米源头池。山体、谷底、积雪、冰体、水盆与流水分别构建，共用世界坐标和高程数据。所有尺寸、水位和命名均为本库创作参数，不是实测地理、冰川或气候资料。

## 四处空间的构建价值

| 场景 | 实际新增 | 对我们的参考与扩展价值 |
| --- | --- | --- |
| 雪脊山岭 | 山脊、较陡裸岩、谷地与单独的积雪覆盖网格 | 先设计大形，再按高程和坡度组织覆盖；可扩展远景方向、登高路径与区域边界 |
| 蓝脊冰川 | 有顶面、底面、侧面和末端的独立冰体，表面沟槽实际改变形状 | 区分山体、冰体与积雪；厚度、宽度、末端和裂隙形态共同构成体积，而不只更换颜色 |
| 冰碛冰湖 | 独立湖盆、244米开放水面、岸带与三块薄冰 | 用盆底、岸线和出入水口组织空间；可继续设计观察点、资源或岸边用途 |
| 融水溪流 | 从244米冰湖降到212米源头池的窄河床与水面 | 把冰雪高地放回完整水网，检查上游、湖面、出口、溪流与原主河的高程联系 |

“冰碛”等名称用于场景叙述，不代表已验证真实地质成因。当前冰川为固定几何，沟槽是形态示意，未模拟裂隙破裂或冰体流动。

## 四步怎样实际对照

1. **山体与冰体**：使用素色地形和素色冰体，保留山谷、冰体厚度与末端形状；隐藏积雪覆盖、水面和附属细节。
2. **雪冰覆盖**：加入独立雪面，冰体呈蓝冰色，裸岩保持冷灰色。覆盖依据本场景的高程、坡度和留白规则生成，不把整片山体涂白。
3. **冰湖与融水**：加入开放湖面、少量薄冰与两段溪流；盆底和河床一直存在，可以隐藏水面检查。
4. **完整冰雪环境**：加入冰缘碎砾、漂砾形态及流纹，保留谷侧、干岸和观看位置。

各站四步使用固定观察位置和方向。积雪有约0.13至0.68米的表面厚度参数，步行高度读取同一雪面规则。模型不模拟真实积雪压实、冰裂隙碰撞或冰面行走；导览沿谷侧和干岸，冰体与深水限制普通步行。

## 冰体与谷地如何贴合

冰川中心线约从（560，-570）延伸至（270，-260），谷底基准从365米降至258米。冰体宽度和厚度沿下游变化，顶面有实际沟槽；中心最薄处约6.56米，边缘逐渐收合。检查中，非出水口的中心冰底与谷地高程一致，未用悬空冰面替代实体。

积雪单独使用覆盖几何：当前网格有10,072个三角面。冰体、河湖内及较陡位置不布置这一覆盖；冷灰山岩、白雪和蓝冰可以分别识别。冰体和有雪覆盖的位置不放地表植物，融水中也不放原温湿水岸的浮叶/芦苇组合。

## 水系怎样连续连接

**冰川末端附近窄溪（258→244米）→ 冰湖（244米）→ 融水溪流（244→212米）→ 原源头池（212米）→ 跌水溪流 → 河谷主河 → 湿地 → 河口 → 海湾（0米）。**

入湖窄溪约66米，出湖融水约119米。冰湖中心床底234米，最大水深10米。窄溪进入冰湖范围前先达到244米，融水进入原池范围前先达到212米，避免相交水面高低错接。湖岸和溪岸采用连续过渡，床底与水面读取同一套宽度、高程与深度数据。

原源头池和约1875米主河保留，新融水没有重画一套下游。这里的连续表示几何与水位连接，没有模拟融化速率、流量、侵蚀、沉积或地下补给。
