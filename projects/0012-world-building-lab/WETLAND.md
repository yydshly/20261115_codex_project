# 河流洪泛、退水与湿地植被

[打开大地图的「洪泛与湿地」](http://127.0.0.1:52932/expedition.html?plan=wetland#build-1)

四站沿中央主河至苇泽湿地布置。每站横断面取同一地图上的实际高程，可以切换水位、退水时间、地表湿润和植被分带。

| 观察站 | 形成条件与可见效果 |
| --- | --- |
| 河道 | 深槽全年有水，保留开水面，挺水植物集中在较浅的边缘 |
| 河漫滩 | 洪水在低处越岸，较高地面只短时受淹，主要布置岸草和柳形树 |
| 季节性湿地 | 低滩反复淹水又露出，细泥和浅层水延缓干燥，莎草形成较密草带 |
| 常年湿地 | 枯水期仍有浅水或饱湿土，布置芦苇和湿岸莎草 |

丰枯水位取已有流域收支的 7 月与 1 月。样带只把能从河槽连通的低点计为当前洪泛，孤立低洼保留原地面。水面按原河床裁切，蓝色高亮表示枯水水面以外目前被淹的低滩，金线保留丰水岸线用于对照。

退水从丰水基准起按 3、7、14、30 天估算。水位向枯水线降低，每格根据何时露出、土壤细粒比例和距水面的高差估算残余湿润。褐色标出丰水淹过而目前露出仍湿的泥面。约 2,041 平方米的低滩在丰水期被淹，示意退水第 7 天约有 1,275 平方米原淹水泥面已经露出且仍湿。这些面积仅限于该样带。

按全年 12 个月的水深和积水频率布置植物。切换季节时，群落位置固定，水面、根区湿润和植被色泽随状态改变。退水时标和湿润指标采用教学参数。湿地植物与淹水的深度、频率、历时和根区缺氧相关，各地植物物种和耐受范围应分别确定。[EPA · 湿地水文与植被](https://www.epa.gov/sites/default/files/documents/wetlands_20hydrology.pdf)

三条环境线可叠加同一植被分带，或按当前月份进入对应站点。水路汇合也可沿河接入本线。

从苇泽继续沿水可带当前月份进入河口，比较淡水湿地与潮间盐湿带。[河口潮汐与咸淡水混合](ESTUARY.md)
