# 洞穴与地下空间：从地表进入同一世界的下层

本轮在盆地西侧山缘增加一段约220米长的地下洞体。洞口、洞道、洞厅与地下水域共享连续洞底、洞壁和拱顶；洞顶上方保留原地表，不将整座山改成凹地，也没有另开一张地下样本地图。

[进入地下段](http://127.0.0.1:52932/expedition.html#cave-1)。当前完整主线为：**平原 → 林缘 → 密林 → 林下 → 林窗 → 盆地 → 洞口 → 洞道 → 洞厅 → 地下水域 → 返回原洞口 → 内陆湖 → 汇流河谷 → 湿地 → 河口 → 海湾**。返回洞口是行进过程，共15个观察站。

## 四个场景的空间作用

| 场景 | 实际构建 | 对我们的参考与扩展价值 |
| --- | --- | --- |
| 山缘洞口 | 原山坡在开口处移除相交三角面；入口地面、岩唇与洞内截面相接 | 组织地上与地下的边界、明暗转折和前进方向；可承接发现入口、区域切换与故事提示 |
| 回声洞道 | 连续截面同时控制干地、两侧洞壁、顶部与净空 | 狭窄空间依赖宽度、高度、转向和可见距离；可扩展岔路、探索节奏和通路选择 |
| 石幔洞厅 | 洞道逐步变宽、变高，上方仍有真实洞顶 | 放大空间并保留围合，提供聚集、遗迹、遭遇与停留的容纳条件 |
| 静潭地下水域 | 地下洞底凹成水盆，27.8米水面覆盖最低22.8米盆底，干岸在旁 | 地下水面也需要床底、岸线、步行边界和观看位置；可扩展渡水、资源或洞内故事 |

场景尺寸、高程和形态都是本库创作参数。洞厅不是任务，地下水也未自动构成玩法，具体内容仍需按我们的目标设计。

## 四层怎样构建

1. **空间骨架**：用素色展示同一洞底、洞壁、拱顶与封闭末端，保留基本照明，先看空腔与净空。
2. **岩层表面**：为同一几何加入分层纹理、岩面粗糙感、潭底与湿岸颜色，不改变洞道形状。
3. **地下水域**：加入独立地下水面，露出水盆与干岸之间的关系；隐藏水面时仍能看到盆底。
4. **完整洞境**：加入石钟乳、石笋、导航灯模型与局部光照，保留通行与观看空间。

地貌站与森林站仍使用各自原来的四步解析。地下段有22组石钟乳/石笋和6处导航灯位置；局部补光在分层对照中保留，灯具模型在完整层出现。灯光、雾和表面流纹属于美术展示，不是物理洞穴光照或地下水流模拟。

## 地表和地下怎样共存

室外沿用原高度场；地下通过连续截面生成洞底、拱顶、两侧洞壁和末端网格。入口处只移除与空腔相交的地表三角面，洞顶以上的山坡照常存在。采样中，干地导览线最小净空约7.35米；进入山体后，洞顶到地表的最小覆盖约24.11米。

同一个水平位置可以有两个高度：洞厅观察点脚下约30.08米，地表约99.51米。移动记录明确区分当前在地上还是地下：地上仍使用原步行表面，地下使用洞底和洞壁边界。进入只通过洞口，深水、侧壁、末端和石笋会限制地下行进，不因相同水平坐标的地表树干而挡住地下通路。

这里是截面式空腔原型，并非任意体素雕刻、布尔地质建模或完整三维物理系统。洞网分支、多出入口、坍塌与攀爬尚未展开。

## 导航、剖视与返回

- **地下导航**：进入地下段后，小地图自动切到同一洞体几何生成的俯看缩略图，直接显示“洞口、洞道、洞厅、地下水域”文字及当前位置。
- **地下剖视**：临时移开对应山体表面、洞顶与近侧洞壁，用顶部线框保留体积提示，看清干地、通道、洞厅与水盆。切回后恢复常规地表开口和洞顶，人的位置不变。
- **地面主线**：这段洞体只有一个入口。水岸之后沿真实洞道返回入口，再沿山缘前往内陆湖，未虚构第二出口或让镜头穿过山顶。
- **重新开始导览**：构建主线会先回到当前观察点，再跟随确定的路线；自由漫游仍可随时接管。

`#cave-1`至`#cave-4`可直接进入四站。完整构建手记扩展为60处，沿用原存储键，保留前44个观察ID及既有浏览记录；未实际浏览的16处地下内容保持待观察。原植被、水系、十站地形路线的记录键不变。

## 验证与边界

[check-cave.mjs](scripts/check-cave.mjs)直接检查实际Three.js几何、洞口三角面移除、默认视线、地下水盆、洞顶覆盖、洞口往返3200处步行、整线12001处支撑、14段实际导览更新函数的2254帧计算、分层控制及剖视恢复。桌面与窄屏剖视相机对四站的地表遮挡另作几何射线检查。

这些是CPU侧几何和控制逻辑检查，不等同于浏览器自动行程或实际点击。浏览器检查工具仍不可用，新增洞穴画面、灯光观感、材质、地下导航文字布局和手机交互尚待复验。没有使用前轮截图或生成图充当新洞穴的实景证据。结果见[验证记录](verification.md)和[cave-check.json](assets/cave-check.json)。

地下水位独立设置，没有模拟地表湖泊渗流补给、流量、水位涨落、真实地质成因或石钟乳生长。当前也没有游泳、潜水、船只、洞穴任务和角色动画。
