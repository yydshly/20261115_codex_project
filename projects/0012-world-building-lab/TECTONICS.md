# 连续地质剖面 · 东南海沟到中央河谷

[进入同一张 3D 大地图](http://127.0.0.1:52932/expedition.html?plan=tectonics#build-1) · [直接看中央河谷横剖面](http://127.0.0.1:52932/expedition.html?plan=tectonics&focus=valley#build-1)

同一地图上的剖面全长约 **6.73 公里**，共 **12 站**。从东南海沟沿陆缘进入火山弧、青岚山前和高山，再越过鞍部到雪岭一侧，沿现有河道到中央河谷。地表、海床和河床都取自现有地图高程，板片构造和覆盖层厚度作示意。地表上方的蓝箭头沿实际中央河道，跨山脊的地质线用于比较两侧地貌。

| 依次观察 | 在地图里看什么 | 地形为什么出现在这里 |
| --- | --- | --- |
| 东南海沟 | 海床凹槽、板块边界与汇聚箭头 | 海洋板块在大陆边缘向下弯折 |
| 大陆架与大陆坡 | 浅水平台、陡坡和深槽之间的高差 | 大陆边缘从较宽的浅水平台过渡至深洋 |
| 海岸前弧 | 海岸到外海海沟之间的陆缘 | 海沟与火山弧之间可形成前弧，部分海底沉积物可被刮削至陆缘 |
| 东部火山弧 | 火口、熔岩场与玄武岩 | 俯冲板片释放流体，促进上覆地幔部分熔融，岩浆上升 |
| 山前逆冲断层 | 浅色岩层在斜断面上错开 | 侧向挤压使上盘沿破裂面上移 |
| 褶皱山前 | 同一条岩层拱起再下弯 | 岩层在挤压下缩短并发生褶皱 |
| 青岚高山 | 山前高差、沟谷、山脊和峰顶 | 地图设定为长期汇聚后形成的内陆构造高地，抬升后受冰雪和流水侵蚀 |
| 青岚结晶岩坡 | 结晶岩上方的原地风化层 | 裂隙与裸露提供风化界面，陡坡和缓坡保留覆盖层的条件不同 |
| 山脊鞍部 | 由青岚侧转向雪岭侧时的实际高差 | 地形较低处提供可读的跨脊位置 |
| 雪岭下游跌水 | 岩阶、窄槽、水面和床底 | 高差集中处可见跌水与较窄的河槽 |
| 出湖河与中央河汇口 | 澄镜湖的出水从另一侧汇入中央河 | 河道沿既有高差下行，在低处汇合 |
| 中央河谷 | 从一岸到另一岸的 160 米横切 | 主槽水面与床底、两岸低滩和下伏基岩可以同框比较 |

在「分区与形成 → 地质与河谷」用上一站和下一站沿线查看。可开关「基岩」「风化与沉积」「河床与水流」，或在全剖面点选观察站。到终点时，局部图默认展示两岸横剖面。俯冲带及风化、侵蚀、沉积的基本机制参照美国国家公园管理局资料。 [俯冲带](https://www.nps.gov/subjects/geology/plate-tectonics-subduction-zones.htm) · [风化、侵蚀和沉积](https://www.nps.gov/subjects/erosion/about.htm)

青岚山前的断层和褶皱共用岩性底图中的砂岩、泥岩分区，山体结晶岩坡样点与岩性和地下水专题相同。中央河谷的冲积覆盖是按现有河槽和低岸条件绘制的解释层，剖面与地图中的水面和床底共用坐标。

## 和三条环境线一起看

- **顺水** 从高差解释融雪汇流，再看流水如何塑造河谷与河口。中央海湾是这条水系的出口，可去东南前弧对照不同海岸位置。
- **南北冷暖** 先看纬度背景，再用青岚高山对照海拔造成的局部冷暖。
- **海岸到内陆** 在西南侧看海上水汽跨过迎风坡和山脊，向东南陆缘与青岚山前对照海陆和高差如何形成。

每条环境线可叠加构造位置标记，也可跳到对应的地质站。返回时保留原环境线、站点与月份。环境缺口的第一项已标为「3D 形成对照已接入」。

## 验证

既有七个构造站已在内置浏览器验收。本次新增剖面用自动检查核对十二站、连续高程、三维图层、河流方向、海面切换、160 米河谷横切和多种视口的取景。新版本的内置浏览器画面仍待实景复核。
