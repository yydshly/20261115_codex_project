# 雨林与红树林：从高林地到河海交界

本库原创的程序化湿热样本，位于现有大地图西南侧；没有切换到独立的小地图。主线追加第58—63站，当前63站252处观察。前段海沟到林缘采用明确标注的教学镜头转场，不作为实际船程或步行道路。

[进入湿热六站](http://127.0.0.1:52932/expedition.html#tropical-1) · [直接观察红树林](http://127.0.0.1:52932/expedition.html#tropical-5)

| 场景 | 实际呈现 | 参考与扩展价值 |
| --- | --- | --- |
| 雨林林缘 | 较高林地与开敞入口、宽冠树和湿土 | 先确定高差与林地边界，再组织由疏到密的入口空间 |
| 林冠 | 高大树干、错层宽冠，距地26m的教学观察镜头 | 地面与冠层分别构建，可扩展更高露头树、冠层生物与高处通行 |
| 林下 | 板根、垂藤、蕨形地被、低灌和头顶树冠 | 用上方围合和下方净空形成完整空间；开合林冠比较实际层次 |
| 河岸 | 从14m下降到0m的淡水河面、真实床底与湿岸 | 先处理岸坡、水位和深槽，再按水陆位置布置植物 |
| 红树林 | 低树宽冠、泥岸、分汊潮沟与伸入泥床的支柱根 | 区分湿润淡水林地与低平盐湿岸地，可继续扩展更多根型、群落与潮汐响应 |
| 河海交界 | 下游两条分汊重新归入主河，再与0m海水连接 | 通过真实高程和水面连接环境，保留开水面与裸泥，不用满屏树木代替生态梯度 |

每站四层为**地形与土壤 → 河网与盐湿 → 乔木与林冠 → 林下与根系**。正式地形、水域判定、植被落点与小地图共用参数。714株雨林乔木与86株红树林，1141个林下/湿岸实例；树冠由树干承接，3372段板根和支柱根端点贴合实际地面，1666段藤蔓从高枝下垂。

林下至河口保留连续实际步行路线，树干与根系退让通路；林冠采用观察镜头升降，不宣称可在树冠上步行。WASD可移动、拖动转向。“打开林冠”仅移开冠层，保留树干与地面；再次点击合上。观察记录与冠层开合独立。湿热全貌查看同一片高林地、河网、泥岸与海口，返回保留观察位置。

湿热、盐湿与植被形态都是创作参数，不代表真实物种、盐度输运、降水量或生态演替。当前水位静态、潮位固定，不包含潮汐涨落和真实红树林生理过程；天气仍使用既有全图系统，热带分区气候尚未模拟。

[tropical-check.json](assets/tropical-check.json)记录五千六百零一个旧路线采样、228个旧观察ID、六站高程与视线、24000个新路线采样、6000个实际步行采样、501个河心水位、三条水带的内部顶点与床底关系、根系落点、分汊连接和实际分层控制器。旧森林、冰雪、地下、高山、生产交通等继续回归。

按用户选择仅提供内置浏览器入口，实景与GPU性能验收暂缓；本轮没有生成或冒充实景截图。草原、戈壁与绿洲已补，见[DRYLAND-WORLD.md](DRYLAND-WORLD.md)；下一步环境优先天空天气，人物与故事仍后置。
