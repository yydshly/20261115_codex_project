# 森林内部：植被怎样形成完整空间

本轮在原大地图的平原北侧建立一片连续林地，基础椭圆范围约280×150米，边缘另有渐变。林缘、密林、林下和林窗是同一片森林中的不同位置，可以沿主线进入并自由移动，没有切换独立样本场景。

[进入森林段](http://127.0.0.1:52932/expedition.html#forest-1)。完整主线现在为：**平原 → 林缘 → 密林 → 林下 → 林窗 → 盆地 → 内陆湖 → 汇流河谷 → 湿地 → 河口 → 海湾**。

## 四处空间分别看什么

| 场景 | 实际组织 | 空间效果与价值 |
| --- | --- | --- |
| 长风林缘 | 从草地到落叶色林地，乔木由疏到密，低灌接住树干空隙 | 形成世界中的边界和入口；可以继续发展岔路、营地、区域提示与情节过渡 |
| 青栎密林 | 高冠树木的树干靠近，树冠在头顶交叠，通道让开树干 | 同时形成顶部、侧向围合与前后遮挡；可以组织探索、隐藏、追踪和路径选择 |
| 蕨影林下 | 高冠下方留净空，近处加入蕨草、低灌、苔垫、树根与倒木 | 把森林变成人能停留和移动的空间；脚边、膝高、腰高与远处树干有不同层次 |
| 晴光林窗 | 中央不种乔木，外围为冠幅退让，中央草花较多，外侧接回阴地蕨草 | 连续树冠中出现真正的开口；可以发展休息点、地标、遗迹、资源或故事节点 |

这些是可承载内容的空间条件，尚未加入探索任务、采集、追踪AI或剧情。

## 在同一位置逐层比较

森林四站使用自己的四步解析，其他地貌继续使用原来的地形、地表、水域、植被四层：

1. **林地基底**：保留原地形与地面覆盖，隐藏树木、林下、地被及倒木。
2. **树冠围合**：加入高冠乔木，比较树干间距、冠幅交叠与头顶净空。
3. **林下层次**：加入蕨草、低灌与贴地倒木，观察人的近景层次和两侧边界。
4. **完整空间**：补上苔垫、草丛与花丛，连接林缘、阴地和林窗的地面变化。

相机在各站的四步对照中使用相同位置和方向。水域保持原有状态，森林生长在露地上；高冠形成上方空间，地被不再承担替代整片森林的职责。植被图层仍支持单独开关。

## 实际生成与光照

林地区域固定分布共**3397个植物实例**：乔木337、林下928、地被2132；另有6根贴地倒木与附着苔块。当前全世界固定植物共18,089个、23种形态，近景草丛另计。数量以[检查结果](assets/forest-check.json)与[分布数据](assets/vegetation-distribution-check.json)为准。

新增两种高冠树形，未直接把原小树等比放大。模板树冠底部约13.2米、顶部约20.6米，实例还有小幅缩放；树干、枝条与根部各有实际几何。树干避开通行带，树冠仍能从两侧伸到通道上方，避免把密林通道清成一条没有树顶的宽走廊。

林窗中央25米半径范围不布置乔木，并额外为冠幅退让。树冠投影覆盖估算使用站点周围20×20米的81点采样：林缘约4%、密林约94%、林下约91%、林窗中心0%。它是冠幅投影的几何估算，不是屏幕像素、真实光照或生态冠层测量。

乔木实际参与方向光阴影。相机位于树冠下时，环境补光依据覆盖估算连续降低，走到林窗时恢复；这是美术控制，不是物理透光模拟。林窗中央草花较多，阴地以蕨草、苔垫和落叶色覆盖为主。

## 与原世界的连接

原平原、盆地、内陆湖、河道与下游保持同一高度场。森林加入既有植物生成规则、根部附着、视点让位和基础阻挡；树干与倒木避开新主线，倒木两端读取各自地面高度。小地图显示林地轮廓及“林缘、密林、林下、林窗”文字，世界全貌将森林段合并为一个入口，避免四个近邻标签堆叠。

完整构建路线从28处扩展为44处观察，沿用原存储键及28个原观察ID；新增16处森林内容。旧植被、水系与地形路线的记录键未变。新版路线站序已有调整，森林段可使用`#forest-1`至`#forest-4`进入。

## 对后续构建的参考

森林空间的设计顺序可以复用为：**地形与地面 → 路径和停留位置 → 树干间距与树冠顶部 → 林下边界 → 开口和远望 → 地被与细节 → 活动和故事**。模型只是其中一层；冠幅、净空、疏密、遮挡与通路共同决定这里能发生什么。

当前实现为原创程序化教学原型，未进行真实物种、光照、生长、天气、季节、风场或森林生态模拟。浏览器检查工具当前不可用，新增场景画面、实际阴影观感、手机布局和完整自动行程尚待复验；CPU几何与控制逻辑检查不能替代画面验收，详见[验证记录](verification.md)。
