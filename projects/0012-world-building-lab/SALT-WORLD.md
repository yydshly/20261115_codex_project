# 内流盐湖、盐沼与干涸湖盆

本轮在同一张3840×3120m大地图的西部增加四站：盐湖 → 盐沼 → 盐壳滩地 → 干涸湖盆。区域为本库创作参数，不代表真实地理区、物种或古水位记录。

[进入四站主线](http://127.0.0.1:52932/expedition.html#salt-1) · [盐沼浅洼](http://127.0.0.1:52932/expedition.html#salt-2) · [盐壳裂纹](http://127.0.0.1:52932/expedition.html#salt-3)

## 实际展示与参考价值

| 场景 | 实际展示 | 对我们的价值与扩展方向 |
| --- | --- | --- |
| 盐湖 | 封闭凹地、中心20m床底，24m/22m两档独立水位；岸线实际收缩 | 区分地形盆底和水位，构建内流盆地；以后可接补给与蒸发过程 |
| 盐沼 | 微起伏、浅水斑块、土丘和湿岸；高水位23.5m，退水参考21.5m | 几十厘米起伏即可组织水陆空间；以后可增加盐湿梯度、鸟类或湿地用途 |
| 盐壳滩地 | 浅白裸地、1026段裂纹盐脊及约0.12m凸起几何 | 地表细节需要贴合实际地面，保留大面积裸露和行走通路；以后可扩展结晶与材质层 |
| 干涸湖盆 | 中央低地、外围高岸与两级旧岸阶地，当前不铺水 | 表现干湿环境的不同阶段与形态；以后可制作实际蓄水和干涸过程 |

## 如何观看

- 世界主线在原地下河后，先沿下层洞廊原路返回中央平台，再经过上层回环与升降回到地表，才进入明确标记的教学转场。没有从地下直接穿岩飞出。
- 四站依次讲解封闭盆地、盐壳湿泥、水位浅洼与耐盐植被。沿东侧干岸步行，所有站点都位于同一片实际地形。
- 在原位置点击“高水位参考”或“退水参考”：湖底保持不动，水网格按同一微地形重新裁切，主场景与小地图同步；高水位盐沼有水洼，低水位样本中这些浅洼露出。
- “盐地全貌”俯看同一区域；小地图使用盐湖、盐沼、盐壳滩地、干涸湖盆文字定位。
- 305簇低草与89株低灌为耐盐群落的程序化形态，布置在稳定干岸与浅洼外围，避开盐壳核心、深水和通路。两档水位不触发生长或重新种植。

## 实现与边界

地形与覆盖接入原高度场，盐湖水面中心水深为4m或2m；盐沼水面以三角形与水位平面相交裁切，土丘不会被完整蓝色圆片盖住。盐壳同时有裂纹线和薄棱几何，干盆两圈阶地有实际高程变化。两档水位只影响本区域，不修改全图海平面、原有河流或地下河。

当前构建主线86站344处，旧82站328个观察ID和浏览器存储键保留。水系14站42处、植被6站18处、地形10站30处不变。

当前没有蒸发、地下补给、水量平衡、盐分输运、晶体生长、真实物种生态或年代地层模拟。高低水位不是连续季节演变；干盆也不会被这两个预设自动灌满。
